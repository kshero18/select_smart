# SelectSmart — Candidate Management Internship Project (2020)

Historical portfolio documentation of a student academic activities and candidate-management project associated with a January–February 2020 internship at Generis Technologies in Bengaluru.

## Background
The internship report describes Excel student uploads, bulk emails, candidate filtering and Excel exports in the broader SelectSmart platform. It separately documents a candidate-management exercise with create, view, edit and delete operations. These should not be assumed to be the same complete codebase.
